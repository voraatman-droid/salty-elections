# The Salty Elections
A simple Monaco × SOCIAL tabletop question randomizer concept.
Open `index.html` in a browser. Press **Randomize questions** to show another prompt. The 16 questions cycle without repeating until the deck is exhausted.
No installation, build step, accounts, timers or digital voting. No player information is collected by the application.
## Files
- `index.html` — responsive yellow-and-blue interface
- `game.js` — question deck and randomizer
The page uses Google Fonts when online and falls back to system fonts otherwise. It can be hosted as a static site, including on GitHub Pages.
This is a campaign concept, not an official Monaco or SOCIAL release.
